I work on **digital signal processing and acoustics** — specifically the design and analysis of **Feedback Delay Network (FDN)** structures for artificial reverberation, and real-time audio-reactive visual systems. Physics student finishing an integrated M.Sc. at Tezpur University. I care about the math that makes sound feel like a room.

---

## Current Research

| Project | What I'm doing |
|---|---|
| **FDN Reverberation** | Analyzing delay-line configurations and ripple smoothness metrics for artificial room acoustics. EDC analysis, modal density, delay distribution — in Python and MATLAB. |
| **Audio-Visual Systems** | Real-time audio-reactive visuals in TouchDesigner. Mapping spectral features (onset, RMS, centroid) to dynamic visual behavior for generative media. |
| **Food Colorant Sensor** | TiO₂ nanoparticle interdigitated electrode sensor for synthetic colorant detection. Signal acquisition and classification pipelines in Python. |
